# Схема базы меняется только миграциями Prisma

Раньше схема применялась через `prisma db push`: быстро, но без истории изменений, и на боевой базе это может молча удалить колонки с данными. С 8 октября 2026 схема меняется только миграциями (`prisma/migrations/` в git): baseline `20261007000000_init` помечен применённым на боевой базе, новые миграции применяются `prisma migrate deploy` перед merge. Миграции пишем совместимыми со старым кодом: сначала добавляем, удаляем — следующей выкаткой.

## Consequences

- `npm run seed` удаляет все данные — запускать только на пустой или тестовой базе.
- Пока у превью нет своей базы, миграции нельзя применять автоматически при сборке Vercel: любой пуш в ветку менял бы боевую базу.
