# Переключатели возможностей в базе по Клубу, закрытый реестр в коде

Статус: proposed (13 ноября 2026, grilling; `docs/stages/stage-4-feature-flags.md`, решения 1–4, 6–10).

Сейчас готовое включают переменными окружения: `GUEST_DEMO`, `MAINTENANCE_MODE`, запреты по `APP_ENV`. Их смена — это новая выкатка на Vercel или перезапуск в Plesk. Прод выкатывается только по решению Владельца, поэтому «код готов» и «возможность включена» должны быть разными событиями. На 256 МБ нужен способ быстро погасить тяжёлое без отката тега. С П2 у каждого Клуба свой набор возможностей.

## Решение

- **Флаги — данные Клуба:** таблица `FeatureFlag` (Клуб, ключ, включён, кто и когда переключил). Все флаги Клуба читаются одним запросом на запрос страницы.
- **Закрытый реестр в коде:** ключ, вид (выпуск или аварийный выключатель), описание, кто переключает, значение по умолчанию, дата «убрать до». Неизвестные ключи в базе игнорируются.
- **По умолчанию** выключатель «работает», флаг выпуска «выключен». Это же значение берётся при сбое чтения.
- **Флаги выпуска переключает Владелец** в админке, **выключатели — разработчик** скриптом или по runbook. Переключение пишется в журнал действий (ADR 0023) и сбрасывает кэш главной, если флаг её касается.
- **Проверка только на сервере.** Выключенное отвечает «Временно недоступно» с кодом 503.
- **Срок жизни флага выпуска:** через два релиза после включения на проде его удаляют из кода. Тест падает, если дата «убрать до» прошла.
- **Окружение — для среды, а не для Клуба:** `APP_ENV`, `MAINTENANCE_MODE` и запреты прода остаются переменными.

## Considered Options

- **Переменные окружения, как сейчас.** Без выкатки не переключить, по Клубу не различить.
- **Внешний сервис (Unleash, LaunchDarkly).** Сторонний вызов на каждом запросе, запись в Политике, деньги, данные вне РК.
- **Доли Посетителей и A/B.** На трафике одного зала выводов не будет, а сложности прибавится.
- **Свободные ключи без реестра.** Опечатка в ключе тихо выключает возможность; забытые флаги никто не удаляет.

## Consequences

- Каждый новый флаг — запись в реестре с датой «убрать до» и тест его ветки «выключено».
- Миграции, вводящие флаг выпуска, заводят его выключенным: выкатка релиза ничего не включает сама.
- Ещё один запрос к базе на страницу. Он вместе с Клубом попадает под кэш данных этапа 7, если замер покажет узкое место.
