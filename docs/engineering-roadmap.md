# Инженерный план развития

Согласовано 17 октября 2026 (grill-with-docs). Термины — GLOSSARY.md, решения — docs/adr.

## Суть
Реальный клиент — Athletic's Gym, боевой сайт https://athleticsgym.kz (hoster.kz) заморожен на теге `v1.0.0`. Развитие идёт в Лаборатории — отдельном проекте Vercel, где сайт превращается в платформу для любого Клуба; Athletic's Gym — первый Клуб и витрина, без личных данных Тренеров и посетителей (ADR 0007). Изменения попадают клиенту только по решению Владельца. Цель — инженерный рост до уровня senior / архитектора; бизнес-задачи вне рамок.

## Компетенции
- **Ядро:** А. Архитектура кода · Б. Доставка и инфраструктура · В. Эксплуатация и наблюдаемость.
- **Фоном, в каждом этапе:** Г. Безопасность · Д. Качество и тестирование.

## Среды и выкатка
- **Лаборатория:** новый проект Vercel `athletics-gym-lab`, база TiDB Cloud Starter, фото — Supabase Storage (dev-проект), бренд и Тарифы Athletic's Gym, Тренеры и Отзывы — вымышленные; `main` → автоматически; превью на каждый PR; закрыта от поисковиков.
- **Прод (клиент):** hoster.kz, тег `v1.0.0`, выкатка только вручную по решению Владельца (ADR 0006). Проект Vercel `athletics-gym` — только перенаправление старого адреса, не трогаем.
- **Совместимость:** код работает в обеих средах, проверка — прод-двойник в CI (ADR 0005).
- **Ветки:** trunk-based, короткие ветки → `main`.

## Витрина для работодателя
README как лендинг (что это, C4, ключевые ADR, цифры) · живой демо-сайт · демо-админка с гостевым входом и ежедневным сбросом данных · страница статуса и SLO · CHANGELOG и журнал этапов.

## Definition of Done этапа
1. ADR — проблема, варианты, выбор, последствия.
2. Диаграмма C4 в docs/architecture/, если изменилась.
3. Тесты на нужном уровне пирамиды.
4. Runbook — выкатка, проверка, откат, действия при сбое.
5. Измерение «до/после».
6. Ретро — 5 строк.

## Темп
Этап — 1–2 недели, 4–5 этапов в квартал; каждый этап живёт в Лаборатории не меньше недели перед закрытием.
