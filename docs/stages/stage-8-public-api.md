# Этап 8 (карты): публичный API (план)

Начат 13 ноября 2026 (grilling, решения 1–13, везде принят рекомендованный вариант). Инженерная суть из `docs/engineering-roadmap.md`: публичный API (по желанию). Не путать с этапом 8 админки — переездом на hoster.kz (ADR 0004). Термины — `GLOSSARY.md`.

## Решения

| # | Вопрос | Решение | Почему |
|---|---|---|---|
| 1 | Для кого | **Только чтение публичных данных Клуба:** прайс, Тренеры, Направления, Залы, часы и контакты. Для агрегаторов, виджетов, чат-ботов. Записи через API, кабинета и мобильного приложения нет | Безопасный минимум: персональных данных нет; запись требует договора с партнёром и решения по ADR 0016 |
| 2 | Формат | **REST + JSON, версия в пути** (`/api/v1/…`). Контракт — OpenAPI 3.1, собранный из схем zod модулей; отдаётся по `/api/v1/openapi.json` | Агрегаторам проще всего REST; один источник правды для проверки и документации; GraphQL ради нескольких списков — лишний слой и память |
| 3 | Доступ | **Открыто, без ключа.** Лимит — 60 запросов в минуту с адреса (хэш IP в памяти процесса, не в базе), сверх — 429 с `Retry-After`. Кэш: ответы статические с ревалидацией, `Cache-Control: s-maxage=300, stale-while-revalidate` | Данные и так открыты на сайте; ключи — когда появится запись или партнёр по договору. Счётчик в базе писал бы на каждый запрос |
| 4 | Совместимость | **В `v1` только добавляем поля.** Удаление или переименование — `v2`, а `v1` живёт ещё 6 месяцев с заголовками `Deprecation` и `Sunset`. Контрактный тест в CI сверяет ответы с OpenAPI | Expand/contract (ADR 0022) — для внешнего контракта |
| 5 | Когда код | **После этапа 4:** API выпускается переключателем возможности на Клуб, выключен, пока Владелец не решит | Этап по желанию |
| 6 | Адреса | `GET /api/v1/club` (название, город, адрес, часы, контакты зала, точка на карте, ссылки 2ГИС и Instagram), `/halls`, `/tariffs?hall=`, `/trainers` (имя, Зал, описание, плакат, персональные Тарифы), `/directions`, `/openapi.json` | То, что уже есть на главной, — без нового смысла |
| 7 | Чего в API нет | **Личных контактов Тренеров** (ждут согласия Владельца), Отзывов (тексты Посетителей и авторы), Обращений, Клиентов, Записей, Окон, скрытых Тарифов, Тренеров и Направлений | Только опубликованное и не персональное; Отзывы — отдельное решение с Политикой |
| 8 | Язык | **`?locale=ru|kk`, по умолчанию ru;** пустой казахский текст — русский, как на сайте. Цены — целые тенге, валюта `KZT` в ответе | Правило сайта; цена без единицы — ошибка агрегатора |
| 9 | Клуб (П2) | **API Клуба — на его адресе** (`CLUB_HOSTS`, ADR 0021). Ссылки на Фото — абсолютные, от основного адреса Клуба | Один механизм выбора Клуба для сайта и API |
| 10 | CORS и поиск | **`Access-Control-Allow-Origin: *` для GET**; `/api` остаётся закрытым в `robots.txt` | Виджеты на чужих сайтах читают из браузера; индексировать JSON незачем |
| 11 | Кэш и правки | **`revalidateSite()` сбрасывает и ответы API**; будущая Цена тарифа (этап 3) появляется в API тем же попутным сбросом в полночь | Прайс в API не должен отставать от сайта |
| 12 | Измерения | Контрактный тест: каждый ответ проходит схему OpenAPI. Прод-двойник: p95 `/api/v1/*` и медиана пика памяти — не выше базы + 5 МБ. Тест лимита: 61-й запрос в минуту — 429. Тест «ничего лишнего»: ни скрытых сущностей, ни запрещённых полей | DoD этапа |
| 13 | Решения и Политика | **ADR 0027** — публичный API только для чтения, версия в пути, OpenAPI из zod, без ключей, лимит в памяти. В Политике — абзац: API отдаёт только опубликованные данные зала, адрес запроса учитывается в памяти для лимита и не хранится | В Политике — только то, что сайт делает на самом деле |

Решения оформлены в ADR [0027](../adr/0027-public-read-api.md).

## Список PR (черновик)

Каждый PR — короткая ветка, мерж только по слову Владельца репозитория. Код — после этапа 4.

1. **Контракт:** схемы ответов в модулях (zod), сборка OpenAPI 3.1, `/api/v1/openapi.json`, контрактный тест.
2. **Адреса `v1`:** Клуб, Залы, Тарифы, Тренеры, Направления — из публичных сервисов модулей; язык, кэш, CORS, сброс из `revalidateSite()`; тест «ничего лишнего».
3. **Лимит и выпуск:** лимит 60 в минуту в памяти, 429; переключатель возможности «Публичный API»; абзац в Политике.
4. **Закрытие:** замер на двойнике, раздел в README, ретро.
