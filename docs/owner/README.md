# Материалы Владельца

Репозиторий публичный. Здесь лежит только то, что и так видно на сайте.

**В git попадает**
- `prices-2026-10.md` — расшифровка прайса: те же цены, что в блоке «Цены».
- `trainers-2026-10.md` — имена, описания и цены Тренеров: то же, что в блоке «Тренеры». Без личных телефонов и аккаунтов.

**В git не попадает** (закрыто в `.gitignore`)
- Исходные плакаты и фото: `docs/owner/**/*.png`, `*.jpg`. На них личные контакты тренеров.
- Переписка с Владельцем, документы с персональными данными, договоры — хранить вне репозитория.

**Правило для новых файлов:** перед коммитом в `docs/owner/` проверить, что в файле нет телефонов, аккаунтов, адресов и других личных данных людей. Контакты самого зала (телефон, WhatsApp, Instagram зала) публичны и допустимы.

Плакаты в `public/trainers/` показываются на сайте целиком, вместе с контактами тренеров, — это решение Владельца; согласие каждого тренера нужно подтвердить (см. `docs/admin-plan.md`, этап 3).
