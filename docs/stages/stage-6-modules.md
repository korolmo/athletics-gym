# Этап 6 — модули с проверяемыми границами

План — `docs/engineering-roadmap.md`: dependency-cruiser в CI, C4, разрез по модулям. Этап ещё не начат: подробный план составляется (grill-with-docs, с 6 ноября 2026).

## Решения (grill-with-docs, 6 ноября 2026)

1. **Хвосты этапа 0 — первые задачи этапа 6**, до разреза на модули: мониторинг UptimeRobot (ADR 0014), job actionlint в CI, повтор подключения к TiDB в `preview-db.mjs` и `seed:lab`. Без живого мониторинга нет недели в Лаборатории и честного «до/после».
2. **UptimeRobot не подключён**: в ветке `monitoring` с 25 октября 0 проверок, тревоги «мало проверок» и «данные устарели» горят. Аккаунт и секрет `UPTIMEROBOT_API_KEY` заводит владелец репозитория; дальше — `uptimerobot-setup.mjs --check` и сверка отчёта на следующий день.
3. **Принцип разреза — модули по сущностям, внутри каждого те же слои** (`domain → validation → services`). Правила слоёв уже есть — dependency-cruiser их проверяет; разрез по сущностям готовит этап П2 (изоляция данных).
4. **Граница модуля — публичный `index.ts`**: снаружи модуля импортировать можно только его `index.ts`; плюс запрет циклов и правила слоёв.
5. **ADR 0015 не существует**: ADR 0014 ссылался на будущий замер первого соединения с TiDB. Ссылка поправлена на этот этап; если решение по тайм-ауту появится — оно станет ADR.
6. **Модули:** Тарифы (Залы, Тарифы, Категории тарифа) · Тренеры (Тренер и его Тарифы) · Направления · Отзывы · Обращения · Фото (Фото, Галерея, хранилище) · Сайт (Настройки сайта, Блоки, Реквизиты) · Аккаунт Владельца (вход, сессия, лимит попыток). Тренеры зависят от Тарифов, обратно — нет. Общая платформа (`db`, логи, i18n, SEO, юридические тексты) — не модуль, а слой под модулями.
7. **Главную собирает модуль «Главная»**: может импортировать все модули, его не импортирует никто.
8. **Фото — базовый модуль**: Тренеры, Направления и Сайт зависят от него, Фото о них не знает. Обратная связь `services/photos.ts` → `SETTINGS_ID` из `services/site.ts` убирается. Событий между модулями нет до этапа 2 (журнал действий).
9. **Код модуля — `src/modules/<имя>/`** со слоями внутри и `index.ts`; перенос — по одному модулю на PR.
10. **Интерфейс остаётся на месте** (`app/`, `components/site`) и импортирует модули только через `@/modules/<имя>` (их `index.ts`).
11. **Ввод проверок постепенно**: dependency-cruiser сначала предупреждает и хранит текущие нарушения как базовую линию; перенесённый модуль переходит в режим ошибки; в конце базовая линия пуста.
12. **«До/после» этапа**: нарушения границ — от числа на входе до 0; пик RSS прод-двойника — не выше ~202 МБ (порог 230); JS для браузера на `/ru` — не больше, чем на входе.
13. **Порядок переноса**: Фото → Тарифы → Тренеры → Направления → Отзывы → Обращения → Аккаунт Владельца → Сайт → Главная.
14. **Подписи** (`lib/presentation/*-labels.ts`) переезжают в свой модуль, часть `presentation`, наружу — через `index.ts`.
15. **Общие помощники админки** (`admin/guard`, `admin/db-errors`, `services/result`, `admin/revalidate`) остаются в платформе `src/lib`. Модули импортируют `lib`, `lib` модули не импортирует.
16. **ADR 0015** «Модули по сущностям с границей через `index.ts`» — в первом PR разреза, вместе с конфигом dependency-cruiser.
17. **C4 компонентов** — `docs/architecture/components.md` (Mermaid, модули и зависимости) вручную; граф dependency-cruiser CI прикладывает к каждому PR для сверки.

## Страницы ошибок — не входят в этап (24 октября 2026)

23 октября сюда был записан долг: два корневых layout и три обхода страниц ошибок, с вариантом «один корневой layout». 24 октября проверка его опровергла (ADR 0013, «Что выяснилось»). `notFound()` рисуется только в браузере даже в чистом приложении Next 15.5 и 16.4 с одним корневым layout. Значит, один корневой layout обходы не убирает. Страницы ошибок переделаны на `global-not-found` и страницу 503 из middleware. Оставшийся долг (код 200 у ошибок админки, `src/pages` ради 500, экспериментальный флаг) пересматривается при переходе на Next 16, а не на этапе 6. Разрез на модули может затронуть layout по своим причинам. Тогда смотреть цифры ниже и смоук Лаборатории.
