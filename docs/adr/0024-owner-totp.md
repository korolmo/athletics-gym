# Двухфакторный вход Владельца: TOTP по желанию, свой код по RFC

Статус: proposed (13 ноября 2026, grilling; `docs/stages/stage-2-journal-2fa.md`, решения 4, 5, 12–14).

В админку входят по логину и паролю. Утечка пароля даёт полный доступ к Тарифам, Тренерам и Записям Клиентов. Владелец входит с телефона, SSH к хостингу нет, а запереть Владельца в собственной админке нельзя.

## Решение

- **TOTP (RFC 6238) по желанию Владельца.** 2FA включается в «Аккаунте» по QR-коду, вместе с ней выдаются 10 одноразовых кодов восстановления. Выключить можно только с текущим кодом. Гость демо-админки 2FA не включает: «Аккаунт» ему закрыт.
- **Секрет зашифрован** AES-256-GCM ключом `TOTP_KEY` из окружения. Коды восстановления хранятся хэшами. Дамп базы и резервная копия второй фактор не дают.
- **Вход в два шага.** После верного пароля выдаётся подписанный токен «пароль пройден» на 5 минут, затем вводится код. Неверные коды считаются в общем лимите попыток входа. Окно — ±1 шаг по 30 секунд.
- **Своя реализация** через HMAC-SHA1 из `node:crypto`, проверенная тестовыми векторами RFC 4226 и 6238. QR-код рисует пакет `qrcode` в SVG, только на странице включения.
- **Потеряны телефон и коды восстановления** — 2FA сбрасывает разработчик SQL-запросом в Plesk (runbook `docs/runbooks/owner-2fa.md`). Сброс попадает в журнал действий при следующем входе.

## Considered Options

- **Обязательная 2FA.** Сильнее, но без постоянного доступа к хостингу потеря телефона запирает Владельца.
- **Пакет `otplib` / `speakeasy`.** Зависимость ради 40 строк, лишняя память на 256 МБ (как с SDK Sentry, ADR 0010).
- **SMS или WhatsApp вторым фактором.** Стоит денег, требует договора, а SIM-swap делает его слабее TOTP.
- **WebAuthn (passkeys).** Сильнее, но сложнее для Владельца и для проверки на hoster.kz. Можно добавить позже.

## Consequences

- Новая переменная `TOTP_KEY` в Plesk и Vercel. Если её сменить, включённую 2FA придётся настраивать заново.
- Вход длиннее на один шаг для тех, кто включил 2FA.
- Runbook сброса 2FA должен быть до выкатки на прод.
