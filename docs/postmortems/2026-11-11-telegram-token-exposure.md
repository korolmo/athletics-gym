# Токен бота уведомлений оказался в журнале рабочей сессии

Статус: закрыт · Среда: Лаборатория · Дата разбора: 13 ноября 2026 (задним числом)

## Кратко
При настройке уведомлений о Записях (этап 1) токен Telegram-бота Лаборатории вывелся открытым текстом в журнал рабочей сессии разработки: маскирование в команде искало переменную с другим именем. В репозиторий, логи сайта и публичные места токен не попал. Его отозвали и заменили в тот же день. Новый токен хранится только в секретах GitHub и передаётся в Vercel при выкатке.

## Влияние
- Пользователи — никакого: бот только шлёт сообщения о вымышленных Записях Лаборатории в тестовый чат.
- Риск: тот, кто прочёл бы журнал сессии, мог бы слать сообщения от имени бота до отзыва токена.

## Хронология
- 10–11.11 — уведомления не доходили (403 от Telegram). Причина — в `TELEGRAM_CHAT_ID` вписан id самого бота. Найдено по тексту ошибки отправщика.
- 11.11 — при проверке переменных токен вывелся в журнал сессии: маска стояла на другое имя переменной.
- 11.11 — токен отозван в BotFather и выпущен новый. Новое значение сначала пришло с лишними 27 символами; обрезано до 46 и проверено вызовом `getMe`.
- 11.11 — токен и чат перенесены в секреты GitHub; `lab.yml` передаёт их при выкатке (`vercel deploy --env`), в переменные проекта Vercel руками их не кладём. Новые Записи и отмены дошли до Telegram.

## Причина
- Маскирование секретов делалось вручную в каждой команде, по имени переменной. Ошибка в имени — и маска молча не срабатывает.
- Отдельно — путаница двух чисел: id бота (часть токена до двоеточия) и id чата.

## Что сработало и что нет
- Сработало: ошибка отправщика с понятным текстом (403 и последние цифры чата) сразу указала на чат. Ротация заняла минуты.
- Не сработало: ручное маскирование.

## Что меняем
| Действие | Зачем | PR / статус |
|---|---|---|
| Отправщик отказывается слать, если чат совпадает с id бота, и пишет об этом | Путаница чисел видна до запроса | сделано (этап 1) |
| Секреты бота — только в секретах GitHub, в Vercel — при выкатке | Одно место хранения, ничего вручную в переменных проекта | сделано (`lab.yml`) |
| Значения секретов не выводим вовсе: проверяем только наличие, длину и ответ API | Маска по имени ненадёжна | правило работы, сделано |
| Ошибки Telegram — без адреса запроса (в нём токен) | Токен не попадает в логи сайта | сделано (`telegram.ts`) |

## Уроки
- Секрет, который нельзя случайно вывести, лучше секрета, который «замаскирован».
- Ротация должна быть дешёвой: одно место хранения и передача при выкатке это обеспечили.
