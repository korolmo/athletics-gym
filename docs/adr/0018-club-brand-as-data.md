# Бренд — данные Клуба, а не код

Статус: proposed (10 ноября 2026, grilling; `docs/stages/stage-p1-brand.md`, решения 2–5, 7, 12–13, 16).

Название «Athletic's Gym», город, логотипы, цвет акцента, ссылки 2ГИС и часовой пояс зашиты в код: `src/lib/site.ts`, `src/lib/brand.ts`, словари, SEO, админка, страницы ошибок, токены `globals.css`, `CLUB_TIME_ZONE`. Чтобы показать платформу, а на П2 завести второй Клуб, бренд должен стать данными.

## Решение

- **Клуб — сущность и базовый модуль `club`** (ADR 0015): одна строка в базе — название, город, описание для поиска (RU/KK), цвет акцента, логотип, ссылки 2ГИС, координаты, часовой пояс. Модуль никого не импортирует. Настройки сайта остаются про тексты главной.
- **Миграция переносит нынешние значения один в один**, тест сверяет их с прежними константами: выкатка на прод сайт не меняет.
- **Тексты — шаблоны.** В словарях `{клуб}` и `{город}`, значения подставляет слой приложения. Упоминаний бренда в коде вне seed, начальных значений и тестов — ноль, тест-счётчик держит это.
- **Тема — только цвет акцента.** Цвет текста на акценте выбирает правило домена; цвет без контраста 4,5:1 с фоном или текстом не принимается. Цвета приходят CSS-переменными из корневых layout, токены `@theme` остаются значениями по умолчанию.
- **Логотип** — загруженное Фото или монограмма из названия (SVG). Иконки вкладки — из того же источника. Логотип Женского зала — необязательное поле Зала.
- **Шрифты остаются в коде.** Пояс в админке не меняется: смена пояса сдвигает Записи — решение П2.

## Considered Options

- **Поля в Настройках сайта.** Быстрее, но название и пояс нужны не только сайту, а на П2 всё равно пришлось бы выносить.
- **Полная палитра или готовые темы.** Свободная палитра ломает контраст; темы — больше кода без новой инженерной сути.
- **Бренд в переменных окружения.** Меняется только выкаткой; Гость демо-админки не увидит результат.

## Consequences

- Страница главной по-прежнему статическая с ревалидацией: сохранение Клуба вызывает `revalidateSite()`.
- Каждый новый текст с названием — через шаблон; тест-счётчик ловит забытое.
- На П2 строк Клуба станет больше, а остальные сущности получат ссылку на Клуб.
