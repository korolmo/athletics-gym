# Athletic's Gym — контекст для Claude

Платформа для фитнес-клуба Athletic's Gym (Кызылорда, ул. Султана Бейбарса, 2а). Сейчас — питч: делаем прототип без договора с залом и показываем владельцу. Общаемся с пользователем по-русски.

## Обязательно
- Термины — только из `GLOSSARY.md` (Тариф, Категория тарифа, Абонемент, Направление, Занятие, Расписание, Тренер, Владелец, Аккаунт Владельца, Посетитель, Отзыв, Обращение, Пробное посещение, Настройки сайта, Блок, Фото, Галерея, Плакат Тренера, Плакат прайса). Новые термины и решения фиксируем по скиллу `domain-modeling`; для проработки новых фич — скилл `grill-with-docs`.
- Решения — в `docs/adr/`. ADR 0001: один Next.js-проект для сайта, кабинета и админки.
- Пользователь работает на Windows (PowerShell). Секреты только в `.env` (в git не попадает).

## Стек
Next.js 15 (App Router, TS) · Tailwind CSS 4 · Prisma 6 · PostgreSQL на Supabase (`DATABASE_URL` — пулер 6543, `DIRECT_URL` — 5432) · деплой Vercel · публичный репозиторий GitHub.

## Код и проверки
- Слои: `lib/domain` (модель и правила) → `lib/validation` (zod) → `lib/services` (правила домена + Prisma, проверка сессии) → server actions (тонкие). К Prisma напрямую ходят только сервисы и лимит входа.
- Сайт: одна секция — один файл в `components/site/sections/`; общие элементы — `components/ui/`.
- Перед коммитом: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` (то же делает CI на каждый PR).
- Схема базы — только миграциями (`npm run db:migrate:dev` на локальной/тестовой базе); порядок выкатки — `docs/deploy.md`. `prisma db push` на боевой базе не использовать.
- Баз две, обе Supabase во Франкфурте, различаются кодом проекта (`docs/deploy.md`): **разработка и превью** — `athletics-gym-dev` (`ptiiovdgxjdcpxlygnrx`), её строки в `.env` и в переменных Preview в Vercel; **боевая** — `vrvupsqjhyhghgikboif`, её строки в `.env.preview` (имя историческое) и в Production. Боевую трогаем только через `npm run db:status:prod` / `db:migrate:prod` и только по явной просьбе пользователя. `npm run seed` на боевой базе отказывается работать без `--force-production`.

## Принятые решения по сайту
- Одна страница, `/ru` (по умолчанию) и `/kk`; казахский текст необязателен — если пуст, показываем русский.
- Целевое действие — Обращение: переход в WhatsApp +7 771 484 63 44 с текстом про Пробное посещение. Форм заявок нет.
- Цены на главной — только реальные, из прайса Владельца (`docs/owner/prices-2026-10.md`), по Залам: переключатель «Общий зал / Женский зал»; «от» = минимум по Категории тарифа. Тренеры — реальные, фото — карточка-плакат целиком (`public/trainers/`); запись — через WhatsApp зала. Расписания и групповых занятий нет.
- Отзывы — только бейдж «5,0 · 405 оценок в 2ГИС» со ссылкой, тексты не копируем. Чужие фото не используем.
- Админка: только Владелец. Аккаунт Владельца — в базе (этап 1): первый вход по `ADMIN_LOGIN` / `ADMIN_PASSWORD` его создаёт, дальше пароль меняется в разделе «Аккаунт»; версия сессии — в аккаунте. Тарифы с фильтром по Залу и Тренеры с их Тарифами (этап 0); раздел «Сайт» — Настройки сайта и показ Блоков (этап 1); загрузка фото — этап 2.
- Тексты и контакты главной, которые меняет Владелец, — в Настройках сайта (база; начальные значения — `src/lib/domain/site-settings.defaults.ts`), секции получают их как `s`. В словарях (`src/dictionaries`) — только подписи из кода. Номер WhatsApp, телефон и Instagram в коде не хранятся.
- Фото (этап 2): файлы — в Supabase Storage, бакет `media`, у каждого проекта свой; в базе только путь (ADR 0002). `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` — только на сервере, без `NEXT_PUBLIC`; работа с хранилищем — только `src/lib/storage/client.ts`. Загрузка: сжатие в браузере → подписанная ссылка от сервера → файл прямо в хранилище → путь в базу; имя файла задаёт сервер. Файл без записи в базе не остаётся (замена, удаление, сбой записи, уборка). Не загружено — показываем картинки из `public/`. Бакет создаёт `npm run storage:setup` / `storage:setup:prod` (боевой — только по явной просьбе). Подробности — `docs/deploy.md`, «Хранилище фото».
- Стиль: сайт свёрстан по макету Stitch (`design/stitch/home-desktop.html`, проект 4810510334939218653): жёлтый #F5E642 на тёмном #131315, шрифт Manrope, иконки Material Symbols (`src/components/symbols.tsx`), токены в `@theme` в `globals.css`. Админка осталась на Oswald + Inter. Фото в `public/stitch/` сгенерированы Stitch — это не съёмка зала; заменить на реальные после согласия владельца.
