# Лаборатория — непрерывная выкатка из main; прод заморожен на релизном теге

Один репозиторий. Короткие ветки на 1–2 дня → `main`; после merge `main` автоматически выкатывается в Лабораторию — отдельный проект Vercel с синтетическими данными демо-Клуба (превью на каждый PR). Боевой сайт клиента на hoster.kz заморожен на теге `v1.0.0` и выкатывается только вручную (запуск workflow + подтверждение в GitHub Environments `production`) и только по решению Владельца. Срочная правка прода — ветка от релизного тега, новый тег `v1.0.x`.

## Considered Options

- Отдельный репозиторий-форк под Лабораторию: разрывает историю проекта, которая и есть доказательство работы с реальным клиентом.
- Автовыкатка `main` на прод: несовместима с заморозкой прода и с тем, что изменения переносятся клиенту только по его решению.

## Consequences

- Проект Vercel `athletics-gym` (перенаправление старого адреса, ADR 0004) не трогаем: Лаборатория — новый проект.
- Ветку `deploy`, которую забирает Plesk, обновляет только ручная выкатка прода.
- Незаконченное в `main` скрывается флагом, пока нет полноценных feature flags (этап 4 плана).
