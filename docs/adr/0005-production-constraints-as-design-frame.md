# Код работает в двух средах: лаборатория на Vercel и боевой хостинг

С 17 октября 2026 развитие ведётся в Лаборатории (отдельный проект Vercel, serverless), а боевой сайт на hoster.kz заморожен (ADR 0006). Изменения из Лаборатории могут однажды попасть на прод, поэтому код обязан работать в обеих средах: Vercel (serverless, нет постоянного процесса, cron на бесплатном плане — раз в сутки) и hoster.kz «Эконом-1» (256 МБ памяти, 1 ГБ диска, Plesk без SSH и Docker, Passenger усыпляет процесс без трафика, MariaDB 10.4). Совместимость с прод-средой проверяет CI на «прод-двойнике» — Docker с лимитами хостинга и MariaDB 10.4.

## Considered Options

- Проектировать только под Vercel: проще, но изменения нельзя будет перенести клиенту без переделки.
- Только под хостинг: лишает Лабораторию превью и удобной демонстрации.

## Consequences

- Периодические задачи для обеих сред — GitHub Actions по расписанию, вызывающий защищённый эндпоинт (Vercel Hobby чаще раза в сутки не умеет, Plesk — вне доступа).
- Состояние между запросами (лимиты, кэши, очереди) — только в базе, не в памяти процесса.
- Внешние сервисы (ошибки, метрики, мониторинг) подключаем только к Лаборатории, где нет персональных данных; на прод — отдельным решением с фильтрацией персональных данных (ADR 0004).
