# Этап 0 — фундамент: заморозка прода, Лаборатория, наблюдаемость

Согласовано 17 октября 2026. План — docs/engineering-roadmap.md; ADR 0005, 0006, 0007.

1. **Заморозка прода.** Тег `v1.0.0` на коммит, из которого собран текущий прод (ветка `deploy`: «Сборка из main f2ad974»). Workflow выкатки на hoster.kz — только вручную (workflow_dispatch с выбором тега) + environment `production` с обязательным ревьюером. Runbook релиза и hotfix.
2. **Лаборатория:** новый проект Vercel `athletics-gym-lab` из того же репозитория; старый проект `athletics-gym` не получает Git-деплоев. База TiDB Cloud Starter, фото — Supabase Storage dev-проекта. noindex.
3. **Данные Лаборатории:** seed с брендом, текстами и Тарифами Athletic's Gym; Тренеры — вымышленные (без плакатов с лицами и контактами), Отзывы и Обращения — синтетические. Копий боевой базы нет. Бренд из настроек — этап П1.
4. **Прод-двойник в CI:** Docker с лимитами хостинга и MariaDB 10.4 — обязательная проверка.
5. **Наблюдаемость (только Лаборатория):** JSON-логи с request_id; Sentry (замер памяти SDK на прод-двойнике, >25 МБ — свой отправщик); /api/health/live, /ready, /api/health; синтетические проверки GitHub Actions → ветка monitoring, SLI/SLO/бюджет ошибок, страница статуса; UptimeRobot для алертов; замер холодного старта на Vercel и на прод-двойнике.
6. **Документы:** README-лендинг (черновик), C4 контейнеров, runbooks (релиз/hotfix, наблюдаемость), цифры «до/после», ретро.
