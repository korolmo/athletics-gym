# Athletic's Gym — контекст для Claude

Платформа для фитнес-клуба Athletic's Gym (Кызылорда, ул. Султана Бейбарса, 2а). Сейчас — питч: делаем прототип без договора с залом и показываем владельцу. Общаемся с пользователем по-русски.

## Обязательно
- Термины — только из `GLOSSARY.md` (Тариф, Категория тарифа, Абонемент, Направление, Занятие, Расписание, Тренер, Владелец, Посетитель, Отзыв, Обращение, Пробное посещение). Новые термины и решения фиксируем по скиллу `domain-modeling`; для проработки новых фич — скилл `grill-with-docs`.
- Решения — в `docs/adr/`. ADR 0001: один Next.js-проект для сайта, кабинета и админки.
- Пользователь работает на Windows (PowerShell). Секреты только в `.env` (в git не попадает).

## Текущая работа
Зал согласился. Делаем админку Владельца по `docs/admin-plan.md` (этапы 1–5, каждый — ветка + превью Vercel).

## Стек
Next.js 15 (App Router, TS) · Tailwind CSS 4 · Prisma 6 · PostgreSQL на Supabase (`DATABASE_URL` — пулер 6543, `DIRECT_URL` — 5432) · деплой Vercel · публичный репозиторий GitHub.

## Принятые решения по сайту
- Одна страница, `/ru` (по умолчанию) и `/kk`; казахский текст необязателен — если пуст, показываем русский.
- Целевое действие — Обращение: переход в WhatsApp +7 771 484 63 44 с текстом про Пробное посещение. Форм заявок нет.
- Цены на главной — только реальные, из прайса Владельца (`docs/owner/prices-2026-10.md`), по Залам: переключатель «Общий зал / Женский зал»; «от» = минимум по Категории тарифа. Тренеры — реальные, фото — карточка-плакат целиком (`public/trainers/`); запись — через WhatsApp зала. Расписания и групповых занятий нет.
- Отзывы — только бейдж «5,0 · 405 оценок в 2ГИС» со ссылкой, тексты не копируем. Чужие фото не используем.
- Админка: только Владелец, логин/пароль из `.env`. Этап 0 (ветка `stage-0-tariffs-trainers`): Тарифы с фильтром по Залу и Тренеры с их Тарифами; загрузка фото — этап 2.
- Стиль: сайт свёрстан по макету Stitch (`design/stitch/home-desktop.html`, проект 4810510334939218653): жёлтый #F5E642 на тёмном #131315, шрифт Manrope, иконки Material Symbols (`src/components/symbols.tsx`), токены в `@theme` в `globals.css`. Админка осталась на Oswald + Inter. Фото в `public/stitch/` сгенерированы Stitch — это не съёмка зала; заменить на реальные после согласия владельца.

## Статус (7 октября 2026)
Сделано и задеплоено: https://athletics-gym.vercel.app (проект Vercel `athletics-gym`, функции в `hnd1`; репозиторий github.com/korolmo/athletics-gym, ветка `main`).
- Главная `/ru` и `/kk` свёрстана по макету Stitch; дизайн главной закрыт. Попиксельное сравнение с макетом — `design/stitch/diff/` (высоты секций совпадают, остаток — наши тексты, обрезанные фото и живая карта).
- Админка Тарифов проверена целиком: вход, изменение цены, скрытие, добавление, удаление — изменения сразу видны на сайте.
- База — Supabase, регион Токио (`ap-northeast-1`); схема и seed применены.
- Деплой — `vercel deploy --prod` из папки проекта; переменные окружения заведены в Vercel (Production).

Этап 0 — в ветке `stage-0-tariffs-trainers`, в `main` не слит: модель Hall, Категории SINGLE / VISITS / UNLIMITED / PERSONAL, Тренеры с персональными Тарифами, блок «С чем помогут тренеры»; модель Lesson, демо-тренеры и «Расписание» удалены. Проверен на локальной базе. Боевая база Supabase ещё на старой схеме: миграцию и seed запускать только после подтверждения пользователя.

Осталось:
- Данные от владельца: исходники логотипов, фото зала (заменить сгенерированные в `public/stitch/`), согласие Тренеров на фото и контакты, проверка казахских текстов носителем, ответы на вопросы из `docs/owner/trainers-2026-10.md`.
- Этапы 1–5 из `docs/admin-plan.md`.
- Личный кабинет Посетителя (см. «Отложено до кабинета»).
- Перенос базы во Франкфурт (`eu-central-1`) и региона функций Vercel вслед за ней — из Кызылорды так быстрее.
