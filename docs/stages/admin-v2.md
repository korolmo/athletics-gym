# Новая админка по макетам Stitch (план)

Решено 8 ноября 2026 (grill-with-docs, вопросы 21–26 этапа 1). Делается внутри этапа 1, до уведомлений через outbox: кабинет Клиента уже в Лаборатории, а экраны Владельца для Записей нарисованы в Stitch в новом виде (`design/stitch/cabinet`: 16, 17, 18, screen.png).

## Решения

| # | Вопрос | Решение | Почему |
|---|---|---|---|
| 21 | Переделываем ли админку | **Да, целиком**: новая оболочка, все разделы переносятся в неё по одному PR | Две админки разного вида путают Владельца |
| 22 | Когда | **Сейчас**, уведомления Владельцу (PR 8 этапа 1) — после | Решение пользователя: экраны Записей уже нарисованы в новом виде |
| 23 | Шрифт и цвета | **Как у сайта**: Onest и токены сайта; Oswald и Inter из админки уходят | Одна система вместо двух; макеты нарисованы так |
| 24 | Меню на телефоне | **4 вкладки + «Ещё»**: Записи, Обращения, Тренеры, Ещё (лист с остальными разделами и «Выйти») | Разделов 10, Записи — каждый день |
| 25 | Меню на компьютере | **Как в макете 17**: боковое меню со всеми разделами, широкая область; в шапке «Сайт ↗», профиль → «Аккаунт», позже — «Не доставлено: N». RU/KZ нет: админка только на русском | По макету |
| 26 | Порядок | **Сначала оболочка** (нынешние разделы работают внутри как есть), затем раздел за разделом по своим макетам Stitch, первым — «Записи» | Маленькие PR, админка всё время рабочая |

## Список PR

1. **Оболочка**: Onest, шапка, боковое меню, нижние вкладки с «Ещё».
2. **Записи** по макетам 16–17: колонки Тренеров на компьютере, карточка Записи снизу на телефоне.
3. **Часы работы Тренера** по макету 18.
4. Остальные разделы — по мере макетов из Stitch (промпты — `design/STITCH-BRIEF.md`, «Новая админка»): Обращения, Тарифы, Тренеры, Направления, Фото, Отзывы, Сайт, Аккаунт, вход, ошибки.
5. «Недоставленные уведомления» (screen.png) — вместе с outbox.

Замер каждого PR: JS публичной главной не меняется (125 kB) — админка грузит свой шрифт отдельно.
