# План: админка Владельца

Согласовано 7 октября 2026 (grill-with-docs). Термины — GLOSSARY.md, решения — docs/adr.

## Принципы
- Структурированная админка, не конструктор: каркас и дизайн страницы в коде, Владелец меняет содержимое и может скрыть любой блок.
- Только Владелец; аккаунт в базе, смена пароля в админке, сброс — через разработчика.
- Всё с телефона: формы и загрузка фото mobile-first.
- RU обязателен, KZ необязателен (пусто → показываем RU). Заголовки секций остаются в коде.
- Фото — Supabase Storage (ADR 0002); перед загрузкой сжимаем в браузере (~1600 px, WebP).
- Аккаунты Vercel/Supabase/GitHub — у разработчика; домен .kz — на зал/Владельца.
- Каждый этап — отдельная ветка → превью Vercel → проверка → merge в main.

Лимит попыток входа сохранён и считает неверный текущий пароль при смене. Сброс забытого пароля — через разработчика (`docs/deploy.md`).

Начальные значения — прежние тексты из словарей: их кладёт миграция (боевая база) и seed.

2. ✅ **Фото и Галерея — сделано 9 октября 2026, в production** (PR #7; устройство — `docs/deploy.md`, «Хранилище фото»; как выкатывали — «Выкатка этапа 2»).
   - **Что загружает Владелец** (раздел «Фото», Плакат Тренера — на странице Тренера): фон первого экрана, фото Женского зала, Галерея (много фото, порядок, подпись RU/KZ, скрыть, удалить), Плакат Тренера, Плакат прайса каждого Зала.
   - **Как идёт загрузка**: браузер сжимает фото до ~1600 px в WebP → сервер проверяет сессию, тип и размер и выдаёт подписанную ссылку → браузер грузит файл прямо в Supabase Storage (бакет `media`) → сервер записывает путь в базу. Имя файла задаёт сервер (uuid). Принимаются JPEG, PNG, WebP до 5 МБ — то же ограничение стоит в настройках бакета.
   - **Файлы не остаются без записи в базе**: при замене и удалении файл убирается из хранилища; если запись в базу не удалась — тоже; загрузки, брошенные на полпути, подбирает уборка (файлы старше часа без ссылки из базы).
   - **На сайте**: первые 8 фото Галереи сразу, остальные по кнопке «Ещё»; Плакат прайса открывается кнопкой в блоке цен. Пока Фото не загружено, показываются прежние картинки из `public/`; демо-картинки Галереи пропадают с первым своим фото.
   - Плакат Тренера из `public/trainers/` остаётся запасным: загруженный лежит в отдельном поле и при удалении уступает место прежнему.

5. ✅ **Отзывы — сделано 9 октября 2026 раньше этапов 3 и 4, в production с 10 октября** (PR #8; как выкатывали — `docs/deploy.md`, «Выкатка этапа 5»).
   - **Отзыв**: имя автора, текст, оценка 1–5, Зал (необязательно), Источник (сайт / 2ГИС / Instagram / Google / другое), ссылка на оригинал (необязательно, только https), дата, Статус (Новый / Опубликован / Скрыт). Текст хранится как написан и показывается на обоих языках без перевода.
   - **Владелец добавляет вручную** (раздел «Отзывы»): такой Отзыв сразу опубликован, его можно править, скрыть и удалить.
   - **Посетитель оставляет на сайте**: имя, оценка, текст, Зал по желанию; телефон и почту не собираем. Отзыв получает Статус «Новый» и не виден до решения Владельца. Его текст Владелец не правит — только публикует, скрывает или удаляет. Имя до 50 символов, текст от 10 до 1000, со ссылками (http, www, домены) не принимается.
   - **Антиспам без капчи**: скрытое поле-ловушка (при срабатывании Посетитель видит обычное «Спасибо», в базу ничего не пишется); не быстрее 3 секунд после открытия страницы (метка времени подписана сервером); не больше 3 принятых Отзывов с одного адреса в сутки (IP — только хэш, как у лимита входа).
   - **Админка**: счётчик новых в меню, фильтр по Статусам, новые первыми. Уведомлений в Telegram нет.

Блок скрывается в разделе «Сайт». Пока опубликованных Отзывов нет, пустой секции нет: от Блока остаются рейтинг 2ГИС и кнопка «Оставить отзыв» с формой.

   - **Не production — не индексируется**: на превью и локально `noindex`, заголовок `X-Robots-Tag` и `Disallow: /` — по `VERCEL_ENV`.
   - **Разметка JSON-LD** типа ExerciseGym из Настроек сайта: название, адрес, координаты, телефон, часы, Instagram, логотип. Рейтинга и Отзывов в разметке нет: оценка взята из 2ГИС, а размечать как свои оценки с других площадок Google запрещает.
   - **Счётчик Обращений**: нажатие на кнопку связи → Канал (WhatsApp / телефон / Instagram), Источник (место на сайте), язык, время. Персональных данных нет: IP не хранится, cookies не ставятся, сторонней аналитики нет. Запись — `navigator.sendBeacon` на `POST /api/contact`; переход по ссылке её не ждёт. Канал и Источник проверяются по списку, лимит 20 в минуту с адреса (хэш адреса только в памяти), нажатия Владельца с активной сессией не считаются.
   - **Главная админки** — «Обращения»: сегодня, 7 и 30 дней, разбивка по Каналам и Источникам, столбики по дням за 30 дней.

## Демо-данные
Редактирование демо-записи снимает с неё пометку «ДЕМО»; удалённые — исчезают. Отзывы — только реальные, с источником; придумывать нельзя.

## Ждём от Владельца
Фото зала (10–20), фото и имена Тренеров с согласием, полный прайс, расписание групповых, исходник логотипа, 3–5 реальных Отзывов, домен.
