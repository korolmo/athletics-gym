# Диагностика хостинга hoster.kz (этап 8, шаг 0)

`plesk-diag.js` — один файл без зависимостей. Запущенный в Plesk как Node.js-приложение, он отдаёт по HTTP отчёт: версии Node, ОС и OpenSSL (для Prisma), лимиты памяти, папки с правом записи и свободное место, исходящий HTTPS, доступность MariaDB на localhost:3306 и `ulimit`. Значения переменных среды не выводит — только имена. По `?stress=1` проверяет, сколько памяти процесс реально может занять.

Отчёт виден любому, кто знает адрес, поэтому после диагностики Node.js выключаем, а файлы удаляем.

## Запуск

1. **Загрузить файл.** Plesk → «Сайты и домены» → athleticsgym.kz → «Менеджер файлов» → папка `httpdocs` → «Загрузить» (значок «+» или стрелка вверх) → выбрать `plesk-diag.js` с компьютера.
2. **Включить Node.js.** «Сайты и домены» → athleticsgym.kz → «Node.js» → «Включить Node.js». Заполнить:
   - Версия Node.js — **23.11.1**;
   - Режим приложения — **production**;
   - Корневой каталог приложения — **/httpdocs**;
   - Корневой каталог документов — **/httpdocs**;
   - Файл запуска приложения — **plesk-diag.js**.

   Кнопки «NPM install» и «Выполнить сценарий» не нажимать. Переменные среды не нужны. Нажать «Перезапустить приложение» (Restart App).
3. **Открыть отчёт:** `http://athleticsgym.kz/diag` (если сертификат уже есть — `https://`). Первая загрузка — до 20 секунд. Выделить весь текст (Ctrl+A, Ctrl+C) и прислать в чат.
   - Адрес именно `/diag`, а не корень: если в `httpdocs` лежит заглушка хостинга `index.html`, на корне откроется она.
4. **Стресс-тест памяти:** открыть `http://athleticsgym.kz/diag?stress=1` и дождаться конца (около 5 секунд). Прислать последние строки. Если страница оборвалась или показала ошибку — это нормально, так мы и узнаём лимит: снова открыть `http://athleticsgym.kz/diag` и прислать раздел «Предыдущий стресс-тест».
5. **Если вместо отчёта ошибка** (страница Passenger, 502/503) — прислать скриншот страницы и скриншот настроек Node.js; журнал — «Сайты и домены» → athleticsgym.kz → «Журналы».

## Выключение и уборка

1. «Node.js» → «Отключить Node.js».
2. «Менеджер файлов» → `httpdocs`: удалить `plesk-diag.js` и `plesk-diag-stress.log` (если есть). Остальное, что было в `httpdocs` до этого, не трогать.
3. Проверить: `http://athleticsgym.kz/diag` больше не показывает отчёт.
