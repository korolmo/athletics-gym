# Athletic's Gym — сайт и админка

Сайт зала Athletic's Gym (Кызылорда) на русском и казахском и админка, в которой Владелец с телефона меняет Тарифы, Тренеров, тексты и контакты сайта.
Термины — в [GLOSSARY.md](./GLOSSARY.md), решения — в [docs/adr](./docs/adr), план админки — в [docs/admin-plan.md](./docs/admin-plan.md).

**Стек:** Next.js 15 (App Router, TypeScript, standalone) · Tailwind CSS 4 · MariaDB 10.4 · Prisma 6 · хостинг hoster.kz (Plesk), ADR 0004.

## Что есть

- `/ru`, `/kk` — одностраничный сайт: первый экран, о зале, «С чем помогут тренеры», Женский зал, цены, галерея, тренеры, контакты с картой. Все кнопки записи ведут в WhatsApp зала.
- **Цены** — из базы, по реальному прайсу Владельца. Переключатель «Общий зал / Женский зал»; карточки по Категориям тарифа с минимальной ценой «от …» и пометками Аудитории и Времени доступа.
- **Тренеры** — из базы, тот же переключатель Залов. Фото Тренера — его карточка-плакат целиком, по нажатию открывается крупно. Под плакатом — персональные Тарифы Тренера и кнопка «Записаться».
- `/admin` — вход по логину и паролю аккаунта Владельца. Аккаунт хранится в базе; первый вход по `ADMIN_LOGIN` / `ADMIN_PASSWORD` из `.env` его создаёт.
  - **Тарифы**: фильтр по Залу, добавление, правка, скрытие, удаление. Форма показывает только поля выбранной Категории.
  - **Тренеры**: фильтр по Залу, добавление, правка имени, Зала, описания, порядка и видимости, персональные Тарифы Тренера, удаление вместе с Тарифами.
  - **Сайт**: Настройки сайта — девиз и подзаголовок первого экрана, карточки «О зале», текст и Instagram Женского зала, контакты (адрес, часы, телефон, WhatsApp, Instagram), рейтинг 2ГИС; переключатель «показывать на сайте» у каждого Блока главной. RU обязателен, KZ необязателен.
  - **Фото**: фон первого экрана, фото Женского зала, Галерея (порядок, подписи, скрытие), Плакаты прайса Залов; Плакат Тренера — на странице Тренера. Фото сжимается в браузере (с копиями 400 и 800 px) и сохраняется на диске хостинга.
  - **Отзывы**: Владелец добавляет настоящие Отзывы вручную (источник, ссылка на оригинал, дата) и решает судьбу Отзывов, оставленных на сайте: опубликовать, скрыть, удалить. Счётчик новых в меню.
  - **Обращения** (главная админки): сколько раз на сайте нажали WhatsApp, телефон или Instagram — сегодня, за 7 и 30 дней, по Каналам и по местам на сайте. Без персональных данных.
  - **Направления**: с чем помогают Тренеры — название, короткое описание, иконка из набора или своё фото; порядок, скрытие, удаление.
  - **Аккаунт**: смена пароля и «Выйти на всех устройствах».
- SEO: title и description на двух языках, canonical и hreflang, `sitemap.xml`, `robots.txt`, превью ссылок, разметка ExerciseGym. В поиск попадает только production; превью и локальный запуск — `noindex`.
- Движение: девиз появляется по словам, бегущая строка, проявление блоков при прокрутке, отсчёт рейтинга, наведение на карточки — только CSS и IntersectionObserver, без библиотек; при «меньше движения» и без JavaScript всё видно сразу.
- Бегущую строку под первым экраном (факты о зале) Владелец меняет сам: «Сайт» → «Бегущая строка».
- Политика конфиденциальности (`/ru/privacy`) и Пользовательское соглашение (`/ru/terms`) — на обоих языках; Реквизиты для них и для подвала Владелец вводит сам: «Сайт» → «Реквизиты». В форме отзыва — обязательное согласие на обработку данных. Карта в «Контактах» грузится по нажатию.
- Главная отдаётся из кэша: страница пересобирается после каждого сохранения в админке и не реже раза в час. Контраст текста — по WCAG AA.
- Групповых занятий и расписания в зале нет — на сайте их тоже нет.

## Модель данных

| Сущность | Что это |
|---|---|
| **Зал** (`Hall`) | `general` — Общий зал, `women` — Женский зал. У каждого свой прайс и свои Тренеры. |
| **Тариф** (`Tariff`) | Позиция прайса Зала или Тренера: Категория, цена (или диапазон «от–до»), число посещений в месяц, срок в месяцах, Время доступа, Аудитория. |
| **Категория тарифа** | `SINGLE` — разовое посещение; `VISITS` — N посещений в месяц; `UNLIMITED` — безлимит, 1 вход в день на N месяцев; `PERSONAL` — персональная тренировка (только у Тренеров). |
| **Время доступа** | `DAY` — дневной, 08:00–17:00; `FULL` — весь день, 08:00–23:00. |
| **Аудитория** | `ALL`, `STUDENTS`, `WOMEN`, `MEN`. Проверяет ресепшен, не сайт. |
| **Тренер** (`Trainer`) | Имя, Зал, фото-плакат, описание (RU/KZ), порядок, видимость и свои персональные Тарифы. |
| **Настройки сайта** (`SiteSettings`, `AboutCard`) | Одна запись с текстами и контактами главной и четыре карточки «О зале»; у каждого Блока — «показывать на сайте». |
| **Аккаунт Владельца** (`Owner`) | Одна запись: логин, хэш пароля, версия сессии. |
| **Отзыв** (`Review`) | Имя автора, текст (как написан, без перевода), оценка 1–5, Зал, Источник, ссылка на оригинал, дата, Статус: Новый / Опубликован / Скрыт. На сайте — только опубликованные. |
| **Фото** | Файл в Supabase Storage (бакет `media`); в базе — только путь: в Настройках сайта, у Зала (Плакат прайса), у Тренера (Плакат) и в `GalleryPhoto` (Галерея). |

Название Тарифа на сайте собирается из полей («12 посещений в месяц», «Безлимит, 3 месяца»); подписи — в `src/dictionaries`.

## Запуск на своём компьютере (Windows, PowerShell)

Нужны Node.js 22+ (`node -v`) и Docker Desktop.

1. **База данных — MariaDB 10.4 в Docker**, как на хостинге: `npm run db:up` (файл `docker-compose.yml`, порт 3307).
2. Скопируйте `.env.example` в `.env` и задайте `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `AUTH_SECRET`.
3. В папке проекта:

   ```powershell
   npm install
   npm run db:migrate
   npm run seed
   npm run dev
   ```

4. Откройте http://localhost:3000 (сайт) и http://localhost:3000/admin (админка).

> `seed` **удаляет** все Залы, Тарифы и Тренеров, заводит их заново из прайса и возвращает Настройки сайта к начальным. На боевой базе (`APP_ENV=production`) откажется работать.

Как на хостинге (собранный сервер, предел памяти): `npm run build`, `node scripts/standalone/assemble.mjs`, `npm run start:standalone` → http://localhost:3100.

## База и выкатка

Хостинг — hoster.kz (Plesk, MariaDB 10.4, ADR 0004). После merge в `main` GitHub Actions собирает сайт в ветку `deploy`, Plesk забирает её и перезапускает приложение; миграции применяются при запуске. Настройка Plesk, перенос данных, переключение и откат — [docs/hosting-plesk.md](./docs/hosting-plesk.md); базы, миграции и выкатка — [docs/deploy.md](./docs/deploy.md).

## Окружения

- **Production** — https://athleticsgym.kz (hoster.kz) после переключения; до него — https://athletics-gym.vercel.app на последнем деплое до этапа 8 (Supabase).
- **Превью** на Vercel отключены: ветки проверяются локально и в CI.
- Секреты — только в `.env` (локально) и в переменных среды Plesk. Файлы `.env`, `.env.preview` и любые `.env.*` в репозиторий не попадают (кроме `.env.example`); в ветку `deploy` — тоже.

## Материалы Владельца

- `docs/owner/prices-2026-10.md`, `docs/owner/trainers-2026-10.md` — расшифровка прайса и карточек Тренеров; по ним написан `prisma/seed.ts`.
- Исходные плакаты (`docs/owner/**/*.png`, `*.jpg`) в репозиторий не коммитятся: на них личные контакты тренеров.
- Плакаты, которые показываются на сайте, лежат в `public/trainers/`.
- Фото в `public/stitch/` сгенерированы — это не съёмка зала; заменить на реальные.

## Структура

```
prisma/schema.prisma          модель данных (Зал, Тариф, Тренер)
prisma/seed.ts                прайс и Тренеры от Владельца
src/app/[locale]/             публичный сайт
src/app/admin/                админка (вход, Тарифы, Тренеры)
src/components/site/          блоки главной; HallBoards.tsx — «Цены» и «Тренеры» с переключателем Залов
src/dictionaries/             тексты RU и KZ
src/lib/                      база, авторизация, языки, справочники Тарифов, данные зала
src/middleware.ts             / → /ru или /kk (запоминает выбор языка)
public/trainers/              карточки-плакаты Тренеров
docs/                         план админки, решения, материалы Владельца
```
