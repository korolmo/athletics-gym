# План: админка Владельца

Согласовано 7 октября 2026 (grill-with-docs). Термины — GLOSSARY.md, решения — docs/adr.

## Принципы
- Структурированная админка, не конструктор: каркас и дизайн страницы в коде, Владелец меняет содержимое и может скрыть любой блок.
- Только Владелец; аккаунт в базе, смена пароля в админке, сброс — через разработчика.
- Всё с телефона: формы и загрузка фото mobile-first.
- RU обязателен, KZ необязателен (пусто → показываем RU). Заголовки секций остаются в коде.
- Фото — Supabase Storage (ADR 0002); перед загрузкой сжимаем в браузере (~1600 px, WebP).
- Аккаунты Vercel/Supabase/GitHub — у разработчика; домен .kz — на зал/Владельца.
- Каждый этап — отдельная ветка → превью Vercel → проверка → merge в main.

## Сделано вне этапов
- **8 октября 2026 — ревью кода** (`docs/review-2026-10-08.md`), в production: безопасность входа и админки, заголовки, тесты и CI, миграции Prisma, слой сервисов. Правила выкатки — `docs/deploy.md`, решение о миграциях — ADR 0003.
- Перенесено из ревью в этап 1: отзыв сессий (S4) — версия сессии уже входит в подпись куки, остаётся хранить её в аккаунте Владельца и увеличивать при смене пароля.

## Этапы
0. ✅ **Сделано 7 октября 2026, в production.** Вместе с Тарифами сделаны Тренеры с персональными Тарифами (создание, правка, удаление; фото — из `public/trainers/`, загрузка — на этапе 2); персональные цены — только у Тренеров. **Тарифы по реальному прайсу** (docs/owner/prices-2026-10.md): сущность Зал (Общий / Женский); новые Категории тарифа — разовое, абонемент на посещения, безлимит, персональная; поля Тарифа — Зал, число посещений, срок в месяцах, Время доступа, Аудитория, цена точная или диапазон. На сайте — переключатель «Общий зал / Женский зал», в админке — фильтр по Залу. Seed заменить реальным прайсом. Владелец ответил: «кешкі» — весь день без ограничений; цена персональных зависит от Тренера (docs/owner/trainers-2026-10.md).
1. **Тексты и контакты**: первый экран (девиз, подзаголовок, фон), «О зале» (4 карточки), Женский зал (текст, Instagram, фото), контакты (адрес, часы, телефон, WhatsApp, Instagram), рейтинг 2ГИС (оценка и число оценок вручную), показ/скрытие блоков. + Смена пароля Владельца (аккаунт из .env переносим в базу). Вместе с этим — отзыв сессий: версия сессии в аккаунте, смена пароля и «выйти везде» её увеличивают (S4 из ревью). Перед этапом — отдельная база для превью.
2. **Фото и Галерея**: загрузка в Supabase Storage, порядок и подписи; на сайте первые 6–8, остальные по «Ещё». Когда загружено ≥3–4 своих фото — фото Stitch убираем полностью.
3. **Тренеры**: имя, Зал, фото (сейчас — карточка-плакат от Владельца целиком), описание, персональные Тарифы Тренера. Запись — через WhatsApp зала (решение 7 октября); на карточках-плакатах есть личные контакты тренеров — согласовать с Владельцем.
4. **Направления**: «С чем помогут тренеры» — добавление/редактирование/скрытие с фото. Групповых занятий в зале нет → Расписания нет.
5. **Отзывы**: (а) Владелец добавляет вручную; (б) Посетитель оставляет на сайте → одобрение Владельцем. Антиспам: поле-ловушка + лимит отправок. Уведомление: счётчик новых в админке (Telegram — позже).

## Демо-данные
Редактирование демо-записи снимает с неё пометку «ДЕМО»; удалённые — исчезают. Отзывы — только реальные, с источником; придумывать нельзя.

## Ждём от Владельца
Фото зала (10–20), фото и имена Тренеров с согласием, полный прайс, расписание групповых, исходник логотипа, 3–5 реальных Отзывов, домен.
